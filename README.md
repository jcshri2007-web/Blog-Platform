# Inkwell — Blog Platform

## 🚀 Overview

Inkwell is a modern blogging platform that allows users to write, publish, and explore stories. It includes authentication, post management, comments, likes, and an admin dashboard.

## ✨ Features

* User authentication (login/register)
* Create, edit, delete blog posts
* Like and comment system
* Categories, tags, and search
* Profile page
* Admin dashboard (manage users & posts)
* LocalStorage-based database

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript (Vanilla)

## 📦 How to Run

1. Download or clone the repo
2. Open `blogplatform.html` in your browser
3. Start using the app
